# 安卓自定义通知

入口：设置 → 系统通知权限 → 通知提醒设置 → 自定义通知。

自定义通知支持标题、内容、触发时刻和六种日期模式：每日、每周、每月、指定日期、多个星期、多个每月日号。每月不存在的日号跳过，不顺延；一次性事件必须选择未来时间。编辑成功后返回列表；返回不会保存草稿；删除同时撤销后续调度和该事件已显示的通知。

日期栏从手机当地的今天起显示连续七天，默认选择今天；列表只显示所选日期的事件，包含当天已到时间的事件，按触发时刻排序。下一条待推送通知独立于所选日期，包含正式通知、按天倒计时和临近提醒，显示实际待推送时间、内容及重复序号。

通知次数与每次间隔在主设置页“通知访问权限”下方统一设置，电量提醒与所有自定义通知共用。默认 1 次、间隔“无”；多次提醒最多 20 次，须设置 1–3600 秒的间隔。升级时保留原配置，两组旧值不同时优先使用自定义通知配置。按天倒计时以事件的日历日期向前计算，每隔 1–365 天在所设时刻提醒；临近提醒可提前 1–10080 分钟开始，每隔 1–1440 分钟提醒，间隔不能超过提前时间。临近阶段暂停按天提醒，到点停止本轮倒计时，开始正式通知。重复事件随后计算下一轮。

事件配置保存在应用私有 SharedPreferences `lanchat_custom_reminders_v1`，统一次数与间隔存于 `background_runtime`；两类调度读取同一份参数。配置不写入聊天数据库，不同步到其他设备。系统通知开关和音效开关适用于这些提醒。下一条提醒由原生调度器计算，前端不负责发送或维持计时器；开启转发后沿用现有通知推送记录保存实际发送结果。
提醒配置仍只保存在本机。可在“推送设置”下开启“自定义通知推送”（默认关闭），将实际产生的正式提醒、倒计时和临近提醒推送到已选设备；无需在应用选择列表勾选 LQChat。点击“应用信息推送（数量）”文字选择应用，右侧开关控制推送；电量开关显示“电量推送”。与电量推送一样，需要推送总开关开启及现有通知传输会话就绪，不会为转发单独启动后台服务。离线设备沿用现有失败记录，不新增补发队列。本机及接收端标题采用“设备名 · 通知标题”，正文保留通知内容或倒计时内容。

后台采用单个 AlarmManager 闹钟，每批同一时刻的通知一起发送，记录已处理标识后计算下批。重启、解锁、应用更新、修改系统时间/时区和重新打开应用时恢复调度。不同通知使用独立 tag，不覆盖聊天通知或电量提醒。为避免过期提醒集中补发，延迟超过五分钟的批次不补发，转到下一次有效时刻。

Android 12 及以上声明 `SCHEDULE_EXACT_ALARM`，由用户在“允许精确提醒”按钮打开的系统页面授权。未授权时使用系统非精确闹钟并显示说明；手机休眠、系统 Doze 或厂商省电限制可能延迟提醒，尤其是秒级连续提醒，不能保证屏幕关闭后的秒级精度。不申请 `USE_EXACT_ALARM`，不新增常驻服务。

```powershell

.\tests\Test-CustomReminderSchedule.ps1
# 设置已有 JAVA_HOME / ANDROID_HOME / GRADLE_USER_HOME 后，在 src-tauri/gen/android 执行：

```
